# Hardware Held

Website voor Hardware Held — gratis ophalen van oude bedrijfshardware in Zuid- en Midden-Limburg, inclusief veilige datawissing.

## Tech stack

- React + TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- Framer Motion
- React Router

## Lokaal starten

```bash
npm install
npm run dev
```

De dev server draait op http://localhost:8080.
